## Spot-check notes

- **Docs that lag code:** `docs/file-format-parity.md` says `.potx`/`.ppsx` are written as `.pptx` and `.thmx` is unreadable. v0.8.0 writes `CT_TEMPLATE`/`CT_SHOW` (`crates/pptx/src/lib.rs:76-84`) and imports `.thmx` through `design.browseTheme` (`crates/engine/src/cmd/design.rs:23, 148-174`). Code wins.
- **SVG wording:** `docs/gaps.md` says SVG files “can’t be inserted”; v0.8.0 `insert.picture` accepts `image/svg+xml` (`crates/engine/src/cmd/insert.rs:366-394`) but does not draw it. The safe instruction is “do not insert SVG”.
- **Print wording:** the project says “no printing”; the UI has a Print page that exports a PDF and opens it (`crates/ui-egui/src/lib.rs:806-828`). Treat it as “PDF-mediated printing”, not a native print dialog.
- **Not tested here:** no GUI launch, no PowerPoint open of an exported `.pptx`, no external deck corpus, no runtime command execution. All claims are code/doc inspection plus `--version`/`--help` on the installed binary.
