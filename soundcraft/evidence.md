## Notes for the reviewer

- **Counting method for row 1.** A raw `cmd!(` grep over `crates/engine/src/cmd/*.rs` gives **397**
  occurrences. Ten of those are not command specs: four macro arms and one doc-comment line in
  `mod.rs`, four helper-macro bodies (`view_more.rs` ×2, `setup_more.rs`, `options.rs`), and the
  `#[cfg(test)]` panic-probe spec. That leaves **387 literal `cmd!` ids**; adding the 94 helper
  invocations and the one direct `CommandSpec` gives **482** (481 + `mix.insert_state`). Helper
  macros are `toggle!` (`options.rs`), `flag!`/`radio!` (`view_more.rs`) and `option!`
  (`setup_more.rs`); no other macro or loop generates specs.
- **v0.12.1 → v0.13.1 delta, measured not assumed.** The same counting/extraction was run over the
  v0.12.1 tree of these paths (fetched from the same upstream tag) and the id sets diffed: 480 → 482,
  added exactly `clip.auto_rename` and `edit.strip_silence_preview`, nothing removed;
  `UI_COMMANDS` 66 → 67, added `view.scroll_into_view`; `REGISTRY` 27 → 30, added `auto_pan`,
  `ring_mod`, `subharmonic`. Parameter-level additions verified by reading both versions:
  `clip.loop.fill`, `edit.strip_silence.mode`/naming, `audiosuite.process` `speed_ramp`,
  `file.bounce_stems.dither`, `file.export_session_text.replace`, `convert --dither/--no-dither`,
  repeatable MCP roots, `Session::validate`, and the panic side-effect restore.
- **Other claims checked but not tabulated:** 512-line menu catalog (`crates/engine/catalog/menus.txt`);
  5 edit modes / 7 tools / 5 fade shapes / 5 timebases / 7 automation modes / 34 channel formats;
  `MAX_BATCH_CALLS = 1000`; `FORMAT_VERSION = 1`; `MAX_CHANNELS = 16`; render budgets
  `1 << 29` (mix) and `1 << 28` (dsp); command gating (a failing `enabled` check still runs when the
  params name targets; `session.new/open/close/revert` and `app.quit` refused while recording);
  `Engine::execute` catches panics, restores the document and side effects and returns
  `EngineError::Internal`; 123 specs carry a shortcut string and several strings collide
  (`Cmd+Alt+L` on `clip.loop` and `edit.move_selection_left`; `Space` on play/stop/toggle).
- **Doc/code divergences labelled in SKILL.md:** `docs/architecture.md` (denies device/buffer
  selection, ASIO, and claims recordings stay in memory), `docs/roadmap.md` alpha-gate rows and
  `docs/gaps.md` G-06 (takes in RAM), `README.md`/`ROADMAP.md` headlines (device choice "missing"),
  `docs/file-format-parity.md` (track presets absent, MIDI export drops controllers/filter),
  `docs/localization-parity.md` (denies the Hangul fallback), `crates/vst3-host/src/lib.rs` header
  (lists `IMessage`/`IAttributeList` as unhosted while `ffi.rs` implements them). Conversely
  `docs/plugin-parity.md` was corrected to 27 + 3 and matches the registry.
- **Uncertain / not runtime-verified:** (a) whether `ui.audio_device` behaves reliably on this macOS
  build — `docs/hardware-parity.md` still marks macOS verification pending; (b) whether a device
  change preserves third-party plug-in state — `apply_audio_config` rebuilds the player without
  calling `capture_plugin_states`, so the skill advises saving first; (c) UI automation behaviour
  (`ui.click`/`ui.drag`/`ui.screenshot`, `ui.dock` transactions through craft-ui's shared
  `DockCommand`) was read from code, not exercised; (d) the `ui.scroll`/`ui.zoom` CLI misrouting was
  derived from `is_control_method`, not run; (e) the craft-libs behaviour behind `craft-docpath`'s

  cloned; rev `16fb3d46e1eaa0d455465e4e66a3ac7b17b55bd3` pinned in `Cargo.toml`).
- **No build, no GUI launch, no audio-device or runtime test.** Only static evidence from the
